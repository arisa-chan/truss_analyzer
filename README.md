A Python code to analyze two-dimensional trusses using the finite element method.

This code was presented by the author to the following:

- to the computer engineering students of STI College Cubao on November 19, 2025 as part of his talk on the math, engineering and coding behind bridge simulator games,
- to the attendees of the PythonAsia 2026 on March 21, 2026 as part of his talk on the application of Python to structural engineering.
- to the attendees of the ASEP Webinar Series W01 on August 29, 2026 as part of his talk on creating finite element analysis applications using Python.
